# 힐 클라이밍 🏍️

가속과 브레이크 두 버튼으로 울퉁불퉁한 언덕을 달리는 오토바이 물리 주행 게임입니다. 서버 없이 `index.html` 만 열면 돌아갑니다.

- 조작: 오른쪽 아래 **가속**, 왼쪽 아래 **브레이크** 버튼을 누르고 있기(폰은 두 엄지). PC 는 `→` `Space` `D` `W` 가속, `←` `↓` `A` `S` 브레이크, `P` 일시정지, `M` 소리. 창이 가려지면 저절로 일시정지합니다.
- 규칙은 `logic.js`(DOM 없음), 화면·소리·입력은 `game.js`. 시험: `node --test`.

## 규칙
- **오토바이**는 바퀴 두 개를 용수철로 땅에 얹은 막대로 계산합니다. 뒷바퀴가 가속하면 차체가 앞으로 밀리면서 **앞이 들리기도** 하고, 언덕에서 튀어 오르면 공중에서 돕니다. **공중에서는 가속 = 앞바퀴 들기, 브레이크 = 앞바퀴 숙이기**. 땅에 닿을 때 바퀴 두 개가 같이 내려앉게 기울기를 맞추세요.
- **머리가 땅에 닿으면** 끝(뒤집힘)입니다. 브레이크는 거의 멈추면 천천히 뒤로 갑니다(한도 있음).
- **연료**: 가속하면 초당 6(쉬움 5) 줄고 안 밟으면 0.7(쉬움 0.6)씩 줄어듭니다. 0 이 되면 굴러가다 **1.5초 동안 거의 멈추면 끝**. ⛽ 연료통은 +50(쉬움 +55)이고 보통 약 1300(쉬움 1100)마다 놓입니다.
- 🪙 코인은 +5점. 점수 = 달린 거리(m, 10 길이 = 1m) + 코인 × 5. **보통의 최고 점수**가 기록입니다(쉬움은 저장 안 함).
- 지형은 끝없이 이어지는 언덕이고(매번 새로 만들어짐), 멀어질수록 경사가 가팔라집니다(보통 최대 약 36°, 쉬움 약 27°).

## 균형을 어떻게 맞췄나 (모의 운전)
- 평지에서 가속하면 1초 안에 최고 속도 300 px/s 에 닿습니다. 처음 힘(330)이 약해 언덕을 오르는 평균 속도가 112 px/s 밖에 안 나와서 연료만 닳아 끝나서, 힘을 460 으로 올렸습니다(평균 210 px/s).
- 모의 운전 20판: 「가속만 계속」은 보통에서 중앙값 약 1270m(14/20 은 뒤집혀 끝, 6/20 은 연료 소진), 쉬움은 약 2000m. 지형의 기울기에 맞춰 공중 자세를 잡는 단순 운전은 보통 약 1300m. 쉬움이 보통보다 훨씬 멀리 갑니다.
- **「가속만 계속 누르기」로도 꽤 멀리 가는 점**은 보통이 아직 너그러울 수 있다는 뜻입니다. **사람의 실제 기록과 체감 난이도는 측정하지 못했습니다.**

## 참고한 것과 제가 정한 값
- 「가속·브레이크로 언덕을 달리는」 널리 알려진 형식을 따랐고, 차체 물리(용수철·구동력·공중 조종), 연료·코인 수치, 지형 경사는 제가 정한 값입니다. 온라인 대전은 없습니다.
